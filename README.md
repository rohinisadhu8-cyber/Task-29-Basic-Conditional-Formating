# Task 29 – Basic Conditional Formatting in Excel

## Project Overview
This project is part of Task 29 of the Veda Technology Internship (Data Analytics Track). The main objective is to learn and apply Excel Conditional Formatting to highlight the top and bottom sales values automatically.

## Objectives
- Understand Excel Conditional Formatting.
- Highlight the Top 10 sales values.
- Highlight the Bottom 10 sales values.
- Improve data readability.
- Apply automatic formatting rules.
- Test different conditions and edge cases.

## Tools Used
- Microsoft Excel

## Dataset
Retail Sales Dataset

## Tasks Completed
1. Created a retail sales dataset.
2. Formatted column headings.
3. Applied Top 10 Items Conditional Formatting.
4. Applied Bottom 10 Items Conditional Formatting.
5. Tested edge cases.
6. Checked formatting rules using Manage Rules.

## Key Learning
- Excel Conditional Formatting
- Top/Bottom Rules
- Automatic data highlighting
- Excel data presentation
- Rule management

## Deliverables
- Formatted Excel workbook
- Conditional Formatting Rules List

Successfully completed Task 29 by applying Basic Conditional Formatting in Excel. This task helped improve my understanding of automatic formatting and data visualization.
